Electricity Market Analysis Using Python

Project Overview 


This project analyzes electricity demand and pricing patterns across NSW and VIC regions using Python.

Tools & Libraries

Pandas
Matplotlib
Seaborn

Analysis Performed

Data Exploration
Demand Distribution Analysis

Data Visualization

Visualizations

Pie Chart
Class Distribution Bar Chart
Correlation Heatmap
Box Plot

Key Findings

NSW and VIC demand showed strong positive correlation.
Transfer showed a negative relationship with VIC demand.
NSW electricity prices showed higher variability and more outliers.
VIC electricity prices appeared relatively stable.
